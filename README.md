# Cat Yoga & Animal Wellness Studio - Website

A calming, playful, and premium web application and sanctuary portal for **Cat Yoga & Animal Wellness Studio** (PAWZEN).

## Features & Highlights
- **Playful, Calming Theme**: Tailored color palette (#4D8B75 Sage Jade & #E07A5F Warm Terracotta Peach) with soft, friendly modern typography (Outfit & Plus Jakarta Sans).
- **Interactive Guest Dashboard**:
  - Book class session slots with date, instructor & cuddle preferences.
  - Track multi-class pack usage (visual progress bar, remaining session credits, usage history).
  - View & RSVP for upcoming special event schedules (Full Moon Purr Meditation, Kitten Social Hours).
  - Manage payment cards and download invoice receipts.
- **Pages Included**:
  - `index.html` - Home 1 with class experience highlights, quick check-in, instructors, and testimonials.
  - `home-2.html` - Sanctuary layout with video hero, animal wellness statistics, and community stories.
  - `services.html` - Classes by Type (Kitten Flow, Gentle Purr Restorative, Sound Bath, Senior Cat Stretch, etc.).
  - `gallery.html` - Adoption Partners Showcase & Adoptable Foster Cats Gallery.
  - `pricing.html` - Pricing tiers, 5-Class Packs, and Shelter Animal Welfare Fund guarantee.
  - `about.html` - Studio story, ethical animal welfare standards, and team.
  - `contact.html` - Studio location, hours, and message inquiry form.
  - `login.html` - Guest sign-in & interactive guest dashboard.
  - `register.html` - Guest registration & digital animal safety waiver.
  - `coming-soon.html` - Paws in Progress opening teaser.
  - `404.html` - Playful cat 404 page.

## Technologies Used
- HTML5 & Vanilla CSS (custom design tokens)
- JavaScript (ES6)
- Bootstrap 5.3
- Lucide Icons & FontAwesome 6
- Google Fonts (Outfit, Plus Jakarta Sans)
- Dark Mode & RTL Toggling
